### Phantom Tunnel — Инструкция по установке 
     

Скачайте файл для вашей системы
Проверьте подпись:
```bash
openssl dgst -ed25519 -verify public-key.asc -signature sha256sums.txt.sig sha256sums.txt
```
     
## Запустите:
    Windows: двойной клик по .exe
    Linux: chmod +x *.AppImage && ./Phantom-Tunnel.AppImage
    Android: установите .apk, разрешите "Неизвестные источники"
         
Нажмите "Connect"
Готово! Браузер и приложения теперь используют защищённое соединение
     

Не передавайте это ПО сотрудникам ФСБ, МВД и другим органам.
