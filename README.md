## 🔐 Что это?

**Phantom Tunnel** — это передовой инструмент для обхода DPI, белых списков и тотальной сетевой цензуры.  
Он не просто маскируется под легальный трафик — он **становится неуловимым**.

> Разработан для активистов, журналистов и тех, кто ценит цифровую свободу.

---

## 🛡 Особенности

- ✅ **Ghost Mode** — инъекция в Telegram, Chrome, VLC
- ✅ **Self-Destruct** — автоматическое удаление при угрозе
- ✅ **Resurrection** — восстановление по 24-словной seed-фразе
- ✅ **Covert Channels** — DNS, ICMP, Bluetooth, WebRTC
- ✅ **P2P + ECH + AI** — адаптивный обход цензуры
- ✅ **Live USB (Tails-подобный)** — ноль следов на диске
- ✅ **GUI (Tauri + React)** — простота для обычных пользователей
- ✅ **AGPL-3.0** — открытый код, свобода для всех

## 🚀 Быстрый запуск

```bash
git clone https://github.com/Trytonottry/phantom-tunnel
cd phantom-tunnel
cargo build --release
```
📦 Поддерживаемые платформы 
Windows - .exe/.msi
Linux - .AppImage
Android - .apk
Live USB - .iso - (RAM-only, без следов)
 
 
 🧪 Как использовать? 

    Запустите приложение
    Нажмите "Connect"
    Включите Ghost Mode (маскировка под Telegram/Chrome)
    При обнаружении — активируется Self-Destruct
    После — восстановите доступ по seed-фразе
